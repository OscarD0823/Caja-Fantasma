# Caja Fantasma 1.21.8 · Cofre custodio y conexión por IP

- Web y celular se conectan sin PC con IP en cuatro casillas, puerto y código de seis números. Android comparte; la web conecta y puede enviar manualmente o sincronizar en vivo.
- Cofre metálico detallado como emblema e icono para Windows, Android y web.
- El módulo Brillante entra en la cerradura, abre la tapa y el fantasma emerge, saluda y se retira. El módulo permanece colocado y el cofre queda visible antes de abrir la interfaz.
- El cofre junto a los puntos comparte las mismas piezas, con una secuencia suave de 14 segundos. Cabeza, brazos, ojos y telas del fantasma tienen movimientos propios.
- Botones con herrajes y reflejos; barra de progreso con energía. Las animaciones respetan movimiento reducido y se pausan al ocultar la aplicación.
- «Registra tus recorridos» identifica las actividades permanentes del mapa. No cambian las reglas de puntos.
- Historial móvil reorganizado por personaje, fecha, puntos y recompensas, con desglose desplegable. Frecuencia por punto y estimación del intento actual aparecen separadas.
- El acceso del propietario no aparece por defecto a visitantes. Publicar el catálogo sigue requiriendo la cuenta GitHub OscarD0823 verificada en Windows.
- El puente móvil persiste antes de confirmar y mantiene las protecciones para copias vacías, cierres de caja y restas intencionales.
- Enlace por IP y código comprobado con un teléfono físico: la web recibió el progreso sin pasar por Windows; el teléfono conservó sus puntos y mostró Web conectado con animación.

El enlace directo necesita ambas apps abiertas en la misma Wi-Fi de confianza. Usa HTTP local, no cifrado de extremo a extremo. El puente existente con PC y su servicio Android en segundo plano se conservan.

Windows y Android consultan el mismo manifiesto de actualización. Android solicita confirmar la instalación; instala encima de la versión anterior, sin desinstalar ni borrar datos. La numeración 1.21.8 también permite actualizar la APK de prueba 1.21.7. La web renueva su caché de interfaz sin borrar el historial local.

Pruebas: dominio, guardado de escritorio, puentes locales, enlaces, PWA e interfaz; 18 casos nativos de guardado y sincronización; compilaciones firmadas Windows x64 y Android ARM64. Los datos personales y claves de firma no se distribuyen.
