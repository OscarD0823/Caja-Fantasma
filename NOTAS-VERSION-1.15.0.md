# Caja Fantasma 1.15.0

## Android y Ruedas Visionales

- Primera APK nativa para Android 8.0 o posterior, optimizada para teléfonos ARM64 y firmada con la identidad de OscarD0823.
- La navegación móvil usa una barra inferior y adapta tarjetas, formularios, historial, personajes y módulos a pantallas verticales.
- La pantalla pública de Visión ya no incluye botones para activar, reiniciar o corregir el ciclo: esas acciones pertenecen exclusivamente al administrador verificado.
- Lunar, Abismo de Gravedad y Progenie Aberrante muestran fichas independientes con su imagen, nombres, descripción y estado público.
- El administrador ve fichas ampliadas de todas las ruedas, puede seleccionar la pública y modificar nombre, traducción, imagen, descripción, disponibilidad, tiempos y recompensas.
- El editor permite crear futuras Ruedas Visionales y conserva todos los cambios como borrador hasta usar el único botón **Guardar todo**.
- Windows y Android continúan recibiendo el catálogo público desde GitHub. Los historiales y configuraciones personales permanecen locales en cada dispositivo.
