# Caja Fantasma 1.16.0

## Sincronización directa y contador más ordenado

- Todos los controles de tamaño, forma, nombre y estilo de la ventana flotante se movieron desde **Visión** al apartado **Caja**, junto al botón que la activa.
- El adicional de Ballena permite ocultar únicamente el tiempo: el Riftwalker y su rayo de progreso continúan visibles. También se puede ocultar por completo desde el mismo panel.
- Windows incluye un botón directo para descargar la APK firmada de esta misma versión.
- Se añadió sincronización bidireccional de los datos personales entre Windows y Android sin Firebase, nube ni cuentas. Funciona mientras ambas aplicaciones están abiertas en la misma red local o mediante anclaje USB.
- El PC muestra su dirección local y un código temporal de seis números; Android usa esos datos para enlazarse y mantener actualizados puntos, cajas, rondas, personajes, historial y módulos Brillantes.
- Los ajustes de cada dispositivo, la posición de la ventana flotante y el acceso de administrador no se copian al teléfono.
- El servicio local rechaza direcciones públicas, limita el tamaño de los mensajes y se apaga al desactivar la función o cerrar el programa.

Usa la sincronización únicamente en una red Wi-Fi de confianza o mediante anclaje USB. Si Windows solicita permiso de red, autoriza solo redes privadas. Si ambos dispositivos cambian los mismos datos al mismo tiempo, se conserva la copia modificada más recientemente.
