# Caja Fantasma 1.20.0

- Sitio estático gratuito en GitHub Pages.
- 12 idiomas seleccionables con fallback seguro al inglés para textos especializados.
- Copia local redundante en localStorage e IndexedDB y caché de la aplicación para uso sin conexión.
- Puente local PC ↔ Web ↔ Android protegido por código de seis dígitos.
- La página no usa Firebase ni servicios con costo y no envía el historial personal al repositorio.
