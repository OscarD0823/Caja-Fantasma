# Caja Fantasma v1.20.5

Esta versión completa la corrección de la resta de puntos entre dispositivos.

- Windows, Android y la página usan un protocolo compatible con eliminaciones sincronizadas.
- El punto eliminado desaparece en los demás dispositivos y una copia atrasada no puede restaurarlo.
- Un dispositivo con una versión anterior muestra que debe actualizarse, en lugar de fallar silenciosamente.
- La página renueva su caché para retirar el código anterior al volver a cargar.

Actualiza todos los dispositivos que participen en Datos en vivo. Los datos existentes se conservan.
