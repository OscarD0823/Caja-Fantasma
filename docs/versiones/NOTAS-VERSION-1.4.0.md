# Caja Fantasma 1.4.0

## Mods Shiny

- Nueva sección para seguir por separado cada módulo nivel 17 que intentas convertir.
- Cada objetivo comienza con 0 intentos; el botón `Otro +17 no se convirtió` suma un fallo y el botón de resta permite corregirlo.
- Cuando obtienes el resultado, `Marcar como Shiny` lo mueve a la colección y guarda la fecha y hora.
- El catálogo permite buscar por nombre en español o inglés y filtrar por nueve estilos de arma o seis piezas de armadura.
- Incluye 100 módulos base actuales: 36 de arma y 64 de armadura.
- `Hora punta · Estrella descendente` viene preparada como selección inicial de ejemplo.
- Se pueden agregar nombres personalizados para módulos futuros.
- El seguimiento Shiny se conserva en el equipo y forma parte de los respaldos JSON.

## Instalación

Descarga `Caja-Fantasma-1.4.0-Instalador.exe`. Las versiones anteriores también pueden recibir esta actualización automáticamente desde GitHub Releases.
