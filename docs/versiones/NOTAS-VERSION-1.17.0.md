# Caja Fantasma 1.17.0

## Novedades

- Sincronización en vivo opcional entre Windows y Android, sin Firebase ni nube personal. Los cambios se reflejan mientras ambas aplicaciones están abiertas y conectadas a la misma red local.
- Los botones manuales **PC → Celular** y **Celular → PC** se conservan para elegir expresamente qué copia reemplaza a la otra.
- Control de revisiones para impedir que un teléfono con una copia atrasada sobrescriba cambios más nuevos del PC.
- Puntos y cantidad de actividades separados por día, con resumen de los últimos días.
- Cada recompensa muestra dos conteos: **Hoy** e **Histórico**.
- Ranking histórico de jefes y recompensas ordenado por la cantidad completada desde que comenzó a usarse la aplicación.
- Nuevo estilo **Solo rayo** para el Riftwalker: el tiempo aparece dentro del haz y el rayo pierde longitud e intensidad a medida que se agota.

## Compatibilidad y privacidad

- El historial diario nuevo se reconstruye con las acciones actuales y cajas ya guardadas cuando se actualiza desde una versión anterior.
- Los datos personales continúan almacenados localmente y solo pasan entre PC y teléfono por la red privada configurada.
- El modo administrador, las credenciales de GitHub y los ajustes exclusivos de Windows no se sincronizan.
