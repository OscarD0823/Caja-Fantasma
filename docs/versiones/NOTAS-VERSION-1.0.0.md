# Caja Fantasma 1.0.0

Primera versión pública del asistente para Once Human.

- Seguimiento ponderado de recompensas Pro y de Rueda Visional.
- Jefes de monolito y silos Pro valen 1; Desafío de Manibus, Guerra Pro y Manibus de Manibus valen 2.
- Ruedas Lunar, Gravedad y Simbiosis; Ballena vale 1 y Plataformas vale 4.
- Simbiosis se conserva desactivada con Araña, Antena y Grandulón sin puntos.
- Registro de salida de cada caja con fecha, hora, puntos, reclamaciones y desglose.
- Estadísticas personales de mínimo, máximo, promedio y probabilidad observada.
- Temporizador cíclico configurable, avisos, bandeja, inicio con Windows y contador flotante.
- Catálogo público sincronizable y editor para publicar futuras ruedas y opciones.
- Actualizaciones firmadas desde GitHub Releases con el mismo patrón seguro de Fortuna Real.
