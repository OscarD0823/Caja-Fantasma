# Caja Fantasma v1.20.1

Esta actualización recupera el enlace entre la aplicación de Windows y la página web sin usar Firebase ni servicios de pago.

- El botón **Abrir página web** abre el navegador y minimiza Caja Fantasma para que la página no quede oculta detrás.
- La página declara el acceso al puente local del PC para activar el permiso exigido por los navegadores actuales.
- Si el navegador bloquea la red local o el PC no responde, la espera termina y aparece una explicación clara sin modificar los datos.
- La sección **Dispositivos** muestra el recorrido **Celular ↔ PC ↔ Página** y las condiciones necesarias para la sincronización en vivo.
- Se corrigió la validación de GitHub y todas las comprobaciones automáticas vuelven a completarse correctamente.

Los historiales, puntos, personajes, cajas y módulos existentes se conservan durante la actualización.
