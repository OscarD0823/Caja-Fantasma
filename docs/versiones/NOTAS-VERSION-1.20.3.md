# Caja Fantasma v1.20.3

Esta actualización unifica la conexión local de los tres sistemas.

- Windows muestra una sola IP, un solo puerto y un solo código para conectar la página y Android.
- La página y el celular pueden permanecer conectados al mismo tiempo.
- El puerto principal reconoce tanto la conexión directa de Android como las solicitudes protegidas del navegador.
- El puente web anterior continúa disponible durante la transición para las páginas que todavía lo tengan guardado.

Los datos existentes se conservan durante la actualización.
