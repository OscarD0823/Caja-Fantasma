# Caja Fantasma 1.10.0

## Apariencia configurable del contador

- Forma automática por evento, rectangular, cuadrada, vertical o redonda.
- Reloj digital, compacto o circular con anillo de progreso.
- Nombre del evento en español, inglés o personalizado por el usuario.
- Las preferencias se guardan localmente y sobreviven al reinicio del programa y del PC.
- La ventana real se redimensiona al cambiar de forma; la Ballena sigue apareciendo como extensión inferior sin quedar recortada.
- El laboratorio del modo desarrollador prueba exactamente la forma, el contador, el nombre y el tamaño elegidos.
- El editor protegido permite definir los nombres español e inglés de ruedas nuevas.

Las actualizaciones continúan firmadas y se distribuyen desde el repositorio oficial de OscarD0823.
