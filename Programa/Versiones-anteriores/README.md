# Versiones anteriores

Archivo histórico de instaladores de Windows y APK de Android que antes estaban en las carpetas principales. Para nuevas instalaciones usa siempre la versión indicada en [`../README.md`](../README.md). Los artefactos y notas de cada lanzamiento también permanecen disponibles en GitHub Releases.

Al publicar 1.22.0 se archivaron aquí 1.21.5, 1.21.6 y 1.21.8, sin eliminar sus archivos ni sus lanzamientos. [Notas de versiones](../../docs/versiones/README.md).

Las versiones 1.16.3, 1.17.0, 1.17.1, 1.17.2, 1.17.3, 1.18.0, 1.18.1, 1.18.2, 1.20.0, 1.20.1, 1.20.2, 1.20.3, 1.20.4, 1.20.5, 1.21.0, 1.21.1 y 1.21.4 quedaron archivadas aquí al publicar sus reemplazos. Las preparaciones locales 1.21.2 y 1.21.3 no fueron lanzamientos públicos; sus mejoras se incluyen en 1.21.4.
