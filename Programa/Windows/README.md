# Windows

- Instalador actual: [`Caja-Fantasma-1.17.0-Instalador.exe`](Caja-Fantasma-1.17.0-Instalador.exe)
- Compatibilidad: Windows 10/11 x64.
- Tamaño: 10.585.029 bytes.
- SHA-256: `1FA1393E2F0E76DCA6140DFA578FDFDC9674C60773175D88367D9189B65A32AD`.

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.17.0 conserva los botones explícitos PC → Celular y Celular → PC e incorpora un modo en vivo opcional para reflejar los cambios automáticamente mientras ambos dispositivos estén abiertos y conectados. El PC también retransmite al teléfono la rueda pública, sus tiempos, fase y retraso de transición. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
