El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.18.2 impide que una copia atrasada no vacía reemplace un historial más completo. Datos en vivo combina registros por identificador y los respaldos comparan el historial duradero, mientras los reemplazos manuales PC → Celular y Celular → PC siguen disponibles con confirmación. Los puntos, actividades y contadores diarios continúan usando un día de juego que cambia a las 8:00 a. m. según la hora de Colombia. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
