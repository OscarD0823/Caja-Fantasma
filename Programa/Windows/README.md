El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.18.0 permite que Android mantenga Datos en vivo en segundo plano mientras este programa de Windows continúa ejecutándose. Conserva la combinación por identificador de registros desfasados, la revisión confirmada, la protección contra estados vacíos, el respaldo nativo, la corrección del socket 10035 y los botones explícitos PC → Celular y Celular → PC. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
