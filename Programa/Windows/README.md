# Windows

- Instalador actual: [`Caja-Fantasma-1.21.1-Instalador.exe`](Caja-Fantasma-1.21.1-Instalador.exe)
- Compatibilidad: Windows 10/11 x64.
- Tamaño: 10.855.473 bytes.
- SHA-256: `F872A39AB0F159C1F5C25EB61D6FE6E1143C5C29B82B8C24916A598BF8DA2506`.

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.21.0 conserva la sincronización simultánea de Windows, página y Android mediante una sola IP, puerto y código. Añade indicadores de dispositivos conectados, un cuadro para la próxima Ballena y su duración, configuración compacta y una apertura con llave, cierres y tapa articulada. Conserva la unión protectora contra pérdidas y la propagación de restas de la versión 1.20.5.

La 1.21.1 añade «Guardar y salir» en el menú y la bandeja, guardado inmediato con la X, antes de actualizar y al apagar, reiniciar o cerrar sesión en Windows. La X guarda y oculta la ventana para seguir en segundo plano; el botón guarda y termina el programa. El respaldo incluye los últimos datos recibidos de otros dispositivos y, si falla, el cierre normal no continúa. La apertura ahora usa caras tridimensionales, herrajes, bisagras e interior de la tapa. Un corte de energía o cierre forzado puede interrumpir cambios todavía no guardados.
