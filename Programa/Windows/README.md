# Windows

- Instalador actual: [`Caja-Fantasma-1.16.3-Instalador.exe`](Caja-Fantasma-1.16.3-Instalador.exe)
- Compatibilidad: Windows 10/11 x64.
- Tamaño: 10.581.448 bytes.
- SHA-256: `E227531BEFF09A8F2DFE19B7A2E50FCAD003608A17E0CE7687B5BEDC0E7980BC`.

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.16.3 muestra por separado la IP, el puerto y el código que se escriben en el celular. Los datos personales se sincronizan mediante botones explícitos PC → Celular y Celular → PC; la comprobación automática solo verifica la conexión. El PC también retransmite al teléfono la rueda pública, sus tiempos, fase y retraso de transición. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
