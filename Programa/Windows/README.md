# Windows

- Instalador actual: [`Caja-Fantasma-1.17.2-Instalador.exe`](Caja-Fantasma-1.17.2-Instalador.exe)
- Compatibilidad: Windows 10/11 x64.
- Tamaño: 10.584.619 bytes.
- SHA-256: `4966C8214D88CD7515C43BECEAC963273A4EE05D24C9C3005A3685E4B2241862`.

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.17.2 evita que un estado vacío borre automáticamente un historial existente durante la sincronización en vivo. Si solo uno de los dispositivos tiene registros al conectarse, esa copia se conserva en ambos; además se guarda una copia local antes de cualquier reducción. Conserva la corrección del socket 10035, los botones explícitos PC → Celular y Celular → PC y la retransmisión de la rueda pública. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
