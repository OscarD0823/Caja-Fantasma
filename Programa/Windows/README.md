# Windows

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.17.1 corrige el error de socket 10035 durante la sincronización frecuente. Conserva los botones explícitos PC → Celular y Celular → PC y el modo en vivo opcional para reflejar los cambios automáticamente mientras ambos dispositivos estén abiertos y conectados. El PC también retransmite al teléfono la rueda pública, sus tiempos, fase y retraso de transición. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
