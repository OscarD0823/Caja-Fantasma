# Windows

- Instalador actual: [`Caja-Fantasma-1.17.3-Instalador.exe`](Caja-Fantasma-1.17.3-Instalador.exe)
- Compatibilidad: Windows 10/11 x64.
- Tamaño: 10.592.581 bytes.
- SHA-256: `2BBA87D2988099396E114134F6A493C602AA737B181B49C7564C62F013945606`.

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.17.3 combina por identificador los registros de dispositivos desfasados y utiliza una revisión confirmada para evitar reemplazos atrasados. También mantiene un respaldo nativo fuera del almacenamiento de la interfaz y recupera automáticamente el historial si el estado principal aparece vacío. Conserva la corrección del socket 10035, los botones explícitos PC → Celular y Celular → PC y la retransmisión de la rueda pública. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
