# Windows

- Instalador actual: [`Caja-Fantasma-1.18.1-Instalador.exe`](Caja-Fantasma-1.18.1-Instalador.exe)
- Compatibilidad: Windows 10/11 x64.
- Tamaño: 10.593.095 bytes.

El instalador contiene Caja Fantasma y su desinstalador. Si Windows no dispone de Microsoft Edge WebView2, puede descargar únicamente el componente oficial necesario para mostrar la interfaz.

La versión 1.18.1 agrupa los puntos, actividades y contadores diarios usando un día de juego que cambia a las 8:00 a. m. según la hora de Colombia. También mantiene Datos en vivo en segundo plano en Android, la combinación por identificador de registros desfasados, la revisión confirmada, la protección contra estados vacíos, el respaldo nativo, la corrección del socket 10035 y los botones explícitos PC → Celular y Celular → PC. Usa una red privada de confianza o anclaje USB y autoriza únicamente redes privadas si el Firewall de Windows muestra una solicitud. La interfaz principal puede mostrarse en español o inglés.
