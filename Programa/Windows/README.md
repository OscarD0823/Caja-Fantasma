# Windows · Caja Fantasma

## Versión 1.21.8

[Descargar instalador](Caja-Fantasma-1.21.8-Instalador.exe) · [Último lanzamiento](https://github.com/OscarD0823/Caja-Fantasma/releases/latest) · [SHA-256](SHA256SUMS.txt)

Windows 10/11 x64. Ejecuta el instalador sobre la versión anterior sin desinstalarla para conservar el progreso. Solo incluye Caja Fantasma y su desinstalador; si falta WebView2, descarga el componente oficial de Microsoft necesario para mostrar la interfaz.

- Recuperación del intento guardado y protección contra puntos ya consumidos por una caja, incluso ante copias atrasadas.
- El módulo Brillante entra en la cerradura; el cofre abre y el fantasma emerge y se retira. El cofre junto a los puntos también está animado. Nuevo emblema compartido por PC, Android y web.
- Botones metálicos, progreso animado e historial móvil reorganizado. Las animaciones respetan movimiento reducido y se pausan al ocultarse.
- Acceso del propietario oculto para visitantes; publicar continúa requiriendo su cuenta GitHub verificada.
- La ventana flotante no sobrescribe el progreso al cerrarla; conserva el estilo y la apertura de la consola de anomalías.
- Una sola instancia: Inicio, búsqueda y accesos directos restauran la ventana existente. El inicio en segundo plano no la muestra.
- **Guardar y salir** guarda y termina el programa. La **X** guarda y deja el programa en la bandeja.
- Respaldo antes de actualizar y al finalizar la sesión de Windows. Un corte de energía o cierre forzado puede interrumpir el último cambio.
- Sincronización local con Android y web mediante la misma IP, puerto y código. Conserva los puntos, las restas intencionales y la protección ante copias atrasadas.

Exporta un JSON desde **Configuración → Respaldo local** antes de cambiar de equipo o desinstalar.
