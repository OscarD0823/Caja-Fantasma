# Caja Fantasma 1.16.3

- Sincronización personal manual y determinista: PC → Celular o Celular → PC.
- El estado automático comprueba la conexión sin sobrescribir datos personales.
- Windows mantiene estable el servidor local al crear o cambiar el código.
- El PC retransmite al celular el catálogo público vigente, incluidos espera, duración, fase y transición en milisegundos.
- Una versión pública superior siempre aplica sus tiempos aunque el reloj local tenga una fecha posterior.
- Los módulos normales abarcan Nivel 1–17 y la versión especial se muestra como Brillante.
- Selector de interfaz Español / English, guardado de forma local en cada dispositivo.
