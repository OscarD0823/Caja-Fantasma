## Default Permission

Permite comprobar actualizaciones y mantener la sincronización local protegida en Android.

#### This default permission set includes the following:

- `allow-check`
- `allow-install`
- `allow-start-background-sync`
- `allow-update-background-sync`
- `allow-read-background-sync`
- `allow-stop-background-sync`
