# Caja Fantasma 1.5.0

## Catálogo completo de Mods Shiny

- El catálogo ahora contiene los 1.825 registros exactos revisados: 207 del sistema anterior, 809 normales 2.0 y 809 Shiny 2.0.
- Todos los registros se pueden añadir como objetivo de conversión y marcar como Shiny conseguido.
- La búsqueda reconoce nombre en español o inglés, variante, estilo, pieza, sistema e ID del objeto.
- Los filtros separan estilos y piezas, sistema anterior, Normal 2.0 y Shiny 2.0.
- Cada resultado muestra su combinación exacta y evita confundir variantes con el mismo nombre base.
- Un segundo buscador permite localizar módulos dentro de los objetivos activos y de la colección personal ya conseguida.
- Se mantienen los registros y respaldos creados en versiones anteriores.
- El generador del catálogo valida automáticamente los conteos antes de aceptar una actualización de datos.

## Instalación

Descarga `Caja-Fantasma-1.5.0-Instalador.exe`. Las versiones anteriores también pueden recibir esta actualización automáticamente desde GitHub Releases.
