# Caja Fantasma 1.19.0

Fecha: 3 de octubre de 2026

## Cambios

- Se eliminó del catálogo visible el sistema antiguo de módulos.
- El buscador incluye 1.618 registros actuales: 809 normales de nivel 1 a 17 y 809 Brillantes.
- Se contrastó el catálogo con las fuentes actuales de la comunidad; las aparentes diferencias restantes eran nombres mal escritos o duplicados ya cubiertos correctamente.
- Nueva animación de inicio con secuencia de acceso, ruta de energía, cerradura, impacto y apertura holográfica, manteniendo intacta la imagen de la caja.
- Nuevo emblema de Caja Fantasma y nuevos iconos para el programa y el instalador.
- La configuración de la ventana flotante se movió a la parte superior del seguimiento.
- Actividad de hoy y el ranking histórico aparecen después de las recompensas Pro y de la rueda activa.
- El idioma se puede cambiar desde la barra superior.
- Se preparó una compilación web para GitHub Pages. En la web, los datos se conservan localmente en el navegador; la sincronización remota opcional queda documentada sin Firebase.

Los historiales, puntos, personajes, cajas y seguimientos de módulos existentes no se migran ni se borran.
